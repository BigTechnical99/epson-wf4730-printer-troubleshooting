## Planned isolation tests — not yet performed
1. Cancel pending phone/computer jobs to prevent automatic resubmission.
2. Use the power button to turn the printer off, let shutdown finish, then restart. Do not interrupt an ink-charging or cleaning cycle.
3. If the error persists, power off and unplug before inspecting accessible paper paths for scraps, foreign objects, or remaining packaging. Do not force the carriage or touch internal ribbon cables/clear strips.
4. If the printer reaches ready with no active errors, load plain paper and use Home → Maintenance → Print Head Nozzle Check → Start. This local test removes the phone/network print path from the test.
5. Record whether paper feeds, whether a pattern prints, and when 000084 reappears.
6. If a pattern prints with gaps, use the guided head-cleaning process and recheck. Do not use repeated cleaning as a treatment for an unresolved printer error.
7. If 000084 recurs on startup or during the local test after the basic checks, contact Epson with the code and results. Do not assign a motor, sensor, or printhead failure without further evidence.
8. If local printing succeeds, return to testing the phone/network connection.
